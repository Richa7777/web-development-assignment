Site Development Report

Learning Experience & Development Journey

Initial Learning Phase

My learning experience in web development started with basic HTML and CSS. Using proper semantic tags was challenging at first, was confused in using elements like elements <div> and <section> or <article> but with this assignment and practice, I slowly learned the importance of semantic HTML.

The hardest part was making the website responsive using proper HTML and CSS.Learning media queries, layouts and debugging CSS took time as the elements did not align well but with the help of inspect element I changed and updated the CSS which aligned well with all the margins and colour combinations.

Development Process

The website was developed in a step-by-step process from using the basic HTML structure for each page and adding CSS for styling the portfolio website. Adjusting the menu to make it responsive took time and needed a careful debugging.

It was really nice to understand the CSS flex, In the beginning layout designing using float was difficult for me but with CSS flexbox the arrangement and alignment of elements was done in more effective and easier way.After understanding all this making contact form with proper validation was simpler than before.

Reflective Discussion

This course has helped me develop knowlwdge in web development as I started without knowing anything about building a web page. Now I am working on a portfolio website styling it with css. I learned fixing problem step-by-step, looking for error, debugging my code, and testing each change as I work on it.

Learning about web accessibility, responsive design for mobile version and semantic tags had helped me in understanding of basic web development. In spite of the fact that I struggled with responsive design and CSS specificity these really helped my problem-solving skills.

Technical & Design Decisions

Technical Implementation

The website was developed coding HTML of first five pages with their CSS aligning together. I used semantic HTML tags to make the work easier and accessable to understand.

All pages uses the same CSS to keep the design consistent for header, footer and more. Also during the development of my web portfolio I took reference from other portfolios, including AI tools and other online resources to improve my design.

Design Choices

The color was choosen based on my personal preference while keeping the design clean and simple. As using the white background color to make the look minimalist with black text to make it look better and readable. This color combinaion made my work formal, clear and simple without unnecessary distraction.

For the text appereance I choose the font sans-serif to make sure it looka clean and readable. For the heading there are separated sections for each page using a hover effect to make it look more interactive. To make the layout more well-orgenized, readeable peoper spacing was important to make sure the website looks formal.

As I exolored for taking reference my design is influenced by modern portfolio websites not the same but I styled it in my own way and according to my preference. I like clean, minimilist structure layouts so these references helped me understand effective page organization which I adapted to suit my design rather than copying from other web developers.
